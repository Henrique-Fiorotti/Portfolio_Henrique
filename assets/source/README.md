# Originais de mídia

Originais das imagens otimizadas e arquivos antigos que não são usados pelo site.
Esta pasta não é servida pelo Next.js. O conteúdo continua versionado no repositório;
isso não torna arquivos confidenciais privados em um repositório público.

Execute `npm run optimize:media` para gerar novamente as prévias WebP em
`public/images/optimized/`. As duas prévias de APIs são cópias locais das imagens
Open Graph dos respectivos repositórios no GitHub.
